# Multi-Platform QA Engineering: API Automation Frameworks & UI Exploratory Testing Repositories

This production-grade QA engineering repository establishes comprehensive validation frameworks across live public cloud microservices and enterprise marketplaces. It showcases end-to-end automated backend contract testing suites and structured user-journey manual exploratory testing frameworks designed to evaluate software stability, input sanitization bounds, and boundary constraints.

## 🛠️ Core Technology Stack & QA Competencies
*   **Automation Testing Framework:** Postman Engine utilizing asynchronous JavaScript execution engines.
*   **Backend Validation Scripts:** Dynamic JSON-Schema property evaluations, conditional runtime wrappers, and isolated environment sandboxing.
*   **UI Exploratory Charter Strategy:** Deployed targeted buyer-journey workflows, whitespace input vector tracking, and cross-browser caching validation.
*   **Defect Architecture Documentation:** Strict root-cause tracking protocols mapping structural replication paths, prioritized severity metrics, and sanitized production evidence.

## 📁 Repository Structural Architecture

### 🔹 Chapter-02: Bikroy Platform API Validation Framework
This directory isolates backend validation scripts executing automated structural verification against listing discovery components (`/v1/listings`).
*   **QA Core Activities:** Deployed multi-layer positive searches, explicit parameter boundary validation blocks (`limit=50`), and input validation filters to protect endpoints without using brittle live-data assumptions.
*   **Framework Architecture:** Utilizes runtime data-type testing (`string`, `number`, `array`) inside variables sandboxing arrays to confirm data shapes remain green even as real marketplace inventories shift.

### 🔹 Chapter-03: News API Automation Engine & Marketplace UI Exploratory Testing
This directory drives dual-scope automation loops running directly on live production cloud web services combined with manual user-journey exploration on public e-commerce channels.
*   **Live Cloud API Test Runner:** Connects to live endpoints (`https://newsapi.org`) to validate dynamic success response shapes, authentication tracking boundaries (`401 Unauthorized`), and successfully exposes real API contract drifts.
*   **Live Marketplace UI Exploratory Charter:** Focuses on a real-world buyer scope ("Find a used phone in Dhaka") on `https://bikroy.com`. Successfully logged data presentation errors and isolated a live input validation vulnerability using sanitized visual proof assets.

## 🎯 Architecture Resiliency & Security Safeguards
1.  **Zero-Leak Credential Compliance:** Rigorous security protocols are maintained by managing gateway authentication variables dynamically via environment profiles. All secret credentials are scrubbed completely clean upon export routines to prevent token leaks.
2.  **Fluid Schema Assertions:** Automation test suites bypass static property matching. Assertions evaluate property shapes and type validation fields natively to absorb changing third-party data inputs seamlessly.
3.  **Ambiguity Defend Isolation:** Captured system drifts and functional validation errors are recorded explicitly within detailed defect reports to demonstrate analytical thinking and deep root-cause validation capacity.
